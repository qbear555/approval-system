========================================
  線上簽核系統 - 獨立安裝包說明
========================================

【系統需求】
- Windows 10 / 11（64 位元）
- 本安裝包已內建 Node.js 與全部相依套件
- 目標電腦不必事先安裝 Node.js / npm

【一鍵安裝（推薦）】
方式 A — 壓縮包一鍵安裝：
  1. 將本資料夾內「Install-ApprovalSystem.bat」
     與「ApprovalSystem-Portable.zip」複製到目標電腦同一資料夾
  2. 雙擊 Install-ApprovalSystem.bat
  3. 依畫面提示完成安裝

方式 B — 已解壓資料夾安裝：
  1. 解壓 ApprovalSystem-Portable.zip
  2. 進入 ApprovalSystem-Portable 資料夾
  3. 雙擊 install.bat（或「一鍵安裝.bat」）

安裝位置：%LOCALAPPDATA%\ApprovalSystem
（例：C:\Users\使用者\AppData\Local\ApprovalSystem）

【安裝後】
  使用網址： http://127.0.0.1:8080/
  或：       http://localhost:8080/
  預設管理員帳號： admin
  預設管理員密碼： admin123
  ※ 請登入後立刻修改密碼，並至「帳號設定」填寫 Email

  本安裝包已含：
  - 全員帳號／部門資料（資料庫 approval.db）
  - 5 個簽核申請表單（請假、出差、請購、一般簽呈、費用報支）
  - 帳號密碼清冊.xlsx（若包內有此檔）
  - workflow-templates 表單 JSON（可再匯入）

  全新安裝會自動帶入上述資料；
  若目標電腦已安裝過，更新時會保留既有資料庫不覆蓋。

  桌面會出現捷徑「線上簽核系統」


========================================
【如何啟用（啟動）伺服器】
========================================

說明：瀏覽器要能開啟簽核系統，必須先「啟動伺服器」。
      伺服器沒啟動時，會出現「無法連線」。

方式 1 — 桌面捷徑（推薦，背景執行、不顯示黑窗）
  1. 雙擊桌面「線上簽核系統」捷徑
  2. 約 2～3 秒後會自動開啟瀏覽器
  3. 網址：http://127.0.0.1:8080/

方式 2 — 開始功能表
  1. 開始功能表 →「線上簽核系統」→「啟動簽核系統」
  2. 等待瀏覽器開啟

方式 3 — 安裝目錄手動啟動
  1. 開啟資料夾：
     %LOCALAPPDATA%\ApprovalSystem
  2. 雙擊 start-background.vbs
     （背景啟動，同桌面捷徑）
  或雙擊 start.bat
     （會顯示黑色視窗；關閉該視窗＝停止伺服器）

方式 4 — 隱藏背景啟動
  雙擊安裝目錄內的 start-hidden.bat
  （不開瀏覽器，只啟動服務；之後自行開啟網址）

【如何確認伺服器已啟用】
  - 瀏覽器可開啟 http://127.0.0.1:8080/ 並看到登入畫面
  - 或在「命令提示字元」執行：
    netstat -ano | findstr :8080
    若出現 LISTENING，表示服務正在執行


========================================
【如何停用（停止）伺服器】
========================================

說明：停止後，所有人（含本機與區網）都無法再連線，
      直到再次啟動伺服器。

方式 1 — 開始功能表（推薦）
  開始功能表 →「線上簽核系統」→「停止簽核系統」

方式 2 — 安裝目錄
  開啟 %LOCALAPPDATA%\ApprovalSystem
  雙擊 stop.bat
  依畫面提示完成（會關閉佔用 8080 埠的程序）

方式 3 — 若用 start.bat 啟動
  在黑色視窗中按 Ctrl + C
  或直接關閉該黑色視窗

【如何確認伺服器已停用】
  - 瀏覽器開啟 http://127.0.0.1:8080/ 會「無法連線」
  - 或執行：
    netstat -ano | findstr :8080
    沒有 LISTENING 即已停止


========================================
【日常使用建議】
========================================
- 上班／需要使用時：雙擊桌面「線上簽核系統」啟用
- 下班／維護時：執行「停止簽核系統」停用
- 重開機後：伺服器預設不會自動跑（除非另有設定），
  請再雙擊桌面捷徑啟動一次
- 若瀏覽器打不開：先確認伺服器是否已啟用，
  再重新整理（Ctrl+F5）


【資料位置（請定期備份）】
  資料庫： %LOCALAPPDATA%\ApprovalSystem\app\data\approval.db
  備份PDF：%LOCALAPPDATA%\ApprovalSystem\app\data\backups
  附件：   %LOCALAPPDATA%\ApprovalSystem\app\data\uploads
  Email設定：%LOCALAPPDATA%\ApprovalSystem\app\data\mail-config.json

【主要功能】
- 註冊／登入、部門、成員管理
- 自訂簽核流程與表單
- 請假／出差等申請、附件、PDF 備份
- 帳號設定：姓名、Email、分機、電話
- Email 提醒：進度通知、催辦簽核人（需在帳號設定配置 SMTP）

【Email 提醒設定（管理員）】
  1. 登入 admin → 帳號設定 → Email 設定
  2. 啟用 Email 提醒，填入公司 SMTP
  3. 寄送測試信確認
  4. 各成員於帳號設定填寫自己的 Email

【區網 / 伺服器部署】
  1. 在伺服器電腦安裝並「啟用」伺服器
  2. Windows 防火牆允許 TCP 8080
  3. 其他電腦瀏覽器開啟：
     http://伺服器IP:8080/
  4. Email 設定中的「系統網址」請改為：
     http://伺服器IP:8080
  5. 不用時在伺服器上執行「停止簽核系統」

【更新版本】
  重新執行新版安裝即可更新程式，會保留既有 data 資料庫。

【解除安裝】
  開始功能表 → 線上簽核系統 → 解除安裝
  或執行安裝目錄 uninstall.bat
  ※ 會刪除程式與資料，請先備份 approval.db
  ※ 解除安裝前建議先「停止」伺服器

【注意】
- 建議僅於公司內部網路使用
- 正式環境請修改預設密碼
- 本包為完整可攜安裝，無需外網下載 Node（打包時已內建）
