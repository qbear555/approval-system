# 一鍵更新說明

有程式變動時，用「更新」即可，**不必重裝**。

| 原則 | 說明 |
|------|------|
| 會更新 | `server/`、`public/`、`package.json`、Docker 相關檔等 |
| **會保留** | `data/`（資料庫、上傳、備份、**Email 設定**、憑證） |
| **不含** | 一鍵包本身**不帶** Email 設定；更新也**不覆寫**正式 `mail-config.json` |

---

## Windows

### A. 同一資料夾已換成新版檔案

1. 進入 `Windows\ApprovalSystem-Portable`
2. 雙擊 **`update.bat`**
3. 會備份 DB／Email → npm install → 重啟

### B. 新版在別的資料夾，要套到舊安裝

1. 開啟新版的 `Windows\ApprovalSystem-Portable`
2. 雙擊 **`套用此包更新到既有安裝.bat`**
3. 輸入舊安裝路徑（例如 `C:\Apps\ApprovalSystem-Portable`）

---

## Ubuntu

### A. 已在安裝目錄覆蓋成新版檔案

```bash
cd /opt/approval-system   # 你的安裝路徑
chmod +x update.sh
./update.sh
```

### B. 新版包在別處

```bash
cd /path/to/一鍵安裝包/Ubuntu
chmod +x 套用此包更新到既有安裝.sh
./套用此包更新到既有安裝.sh /opt/approval-system
```

---

## NAS（Synology）

### A. 從這台 Windows 直接部署到 NAS（最省事）

1. 確認 `D:\一鍵安裝包\NAS\ApprovalSystem-NAS-Install` 已是新版  
2. 雙擊 **`NAS\一鍵更新-從這台電腦部署到NAS.bat`**  
3. 輸入 NAS IP／SSH 帳密  
4. 腳本會：`NAS_SKIP_DB=1` 上傳程式、重建容器、**保留 data 與 Email**

（需本機有 Node.js，且開發專案存在：`%USERPROFILE%\Documents\approval-system`）

### B. 手動上傳後在 NAS 更新

1. File Station 上傳新版檔案到 `/docker/approval-system`（**不要覆蓋整個 data/**）  
2. SSH：

```bash
cd /volume1/docker/approval-system
chmod +x update.sh
sudo ./update.sh
```

---

## 建議流程（開發端有改動時）

1. 在開發專案改程式並驗證  
2. 同步到 `D:\一鍵安裝包` 三平台（`scripts\sync-oneclick-packages.ps1`）  
3. 對正式環境執行對應平台的 **一鍵更新**  
4. 登入系統確認版本／功能；Email 應仍為原設定  

---

## 注意

- 更新前腳本會嘗試把 `approval.db`、`mail-config.json` 備份到 `data/_update_backup/`  
- 若 `package.json` 新增依賴，Docker 會 rebuild；Windows 會跑 `npm install`  
- **首次安裝**仍用各平台 `install`／`install.bat`／`install.sh`，不要用 update
