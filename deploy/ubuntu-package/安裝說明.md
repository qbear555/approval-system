## 1. 安裝包內容

解壓後主要結構如下：

```
ApprovalSystem-Ubuntu-Install/
├── 00-請先讀我.txt          ← 快速入門
├── 安裝說明.md              ← 本文件
├── install.sh               ← ★ 一鍵安裝主程式
├── uninstall.sh             ← 解除安裝
├── status.sh                ← 狀態檢查
├── backup-data.sh           ← 打包 data 備份
├── docker-compose.yml
├── Dockerfile
├── env.example
├── package.json
├── package-lock.json
├── server/                  ← 後端
├── public/                  ← 前端
├── fonts/                   ← PDF 中文字型
└── data/                    ← 資料（資料庫、附件、備份）
    ├── approval.db          ← （可選）預置資料庫
    ├── uploads/
    └── backups/
```

| 檔案 | 用途 |
|------|------|
| `install.sh` | 互動式一鍵安裝（Docker 或原生） |
| `uninstall.sh` | 停止服務並可選擇清除 data |
| `status.sh` | 查看容器／systemd／埠／HTTP |
| `backup-data.sh` | 將 `data/` 打成 tar.gz |
| `data/` | **所有業務資料**，遷移時務必保留 |

## 2. 安裝前準備

### 2.1 硬體與網路

- CPU：1 核心以上  
- 記憶體：建議 ≥ 1 GB  
- 磁碟：建議 ≥ 2 GB 可用空間（含附件與備份會再增加）  
- 網路：安裝時需可連線下載 Docker 或 Node.js  

### 2.2 權限

- **Docker 模式**：首次安裝 Docker 需要 `sudo`；之後可用一般使用者（需在 `docker` 群組）  
- **原生模式**：必須 `sudo ./install.sh --native`  

### 2.3 上傳安裝包

將整個資料夾傳到 Ubuntu，例如：

```bash
# 在您的電腦（範例）
scp -r ApprovalSystem-Ubuntu-Install user@192.168.x.x:/tmp/

# 在 Ubuntu 上
sudo mv /tmp/ApprovalSystem-Ubuntu-Install /opt/approval-system
cd /opt/approval-system
```

也可用 USB、FileZilla、WinSCP、rsync 等方式。

## 3. 一鍵安裝步驟

```bash
cd /opt/approval-system          # 改成您的實際路徑
chmod +x install.sh uninstall.sh status.sh backup-data.sh
./install.sh
```

畫面會出現選單：

```
1) Docker Compose（建議）
2) 原生 Node.js + systemd
3) 取消
```

依提示選擇後等待完成，瀏覽器開啟：

```
http://<Ubuntu的IP>:3847
```

### 非互動安裝（腳本／自動化）

```bash
# Docker
sudo ./install.sh --docker -y

# 原生
sudo ./install.sh --native -y --port 3847
```

## 4. 方式 A：Docker 安裝（建議）

### 4.1 原理

- 使用本目錄的 `Dockerfile` 建置映像  
- `docker-compose.yml` 將主機 `./data` 掛載到容器 `/app/data`  
- 容器重啟、升級程式時，**資料不丟失**（只要不刪 `data/`）  

### 4.2 手動安裝（等同 install.sh --docker）

```bash
# 若尚未安裝 Docker
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER
# 重新登入

cd /opt/approval-system
cp env.example .env
nano .env    # 修改 JWT_SECRET

mkdir -p data/uploads data/backups
docker compose up -d --build
docker compose ps
docker compose logs -f
```

### 4.3 驗證

```bash
./status.sh
curl -s http://127.0.0.1:3847/api/departments
```

### 4.4 常用指令

| 操作 | 指令 |
|------|------|
| 查看狀態 | `docker compose ps` |
| 看日誌 | `docker compose logs -f --tail=100` |
| 重啟 | `docker compose restart` |
| 停止 | `docker compose down` |
| 更新程式後重建 | `docker compose up -d --build` |

## 5. 方式 B：原生 Node + systemd

### 5.1 適用情況

- 不想安裝 Docker  
- 需要直接用 `journalctl` 看日誌  
- 公司規範限制容器  

### 5.2 安裝

```bash
cd /opt/approval-system
sudo ./install.sh --native
```

會自動：

1. 安裝 Node.js 22  
2. `npm install --omit=dev`  
3. 寫入 `/etc/default/approval-system`（含隨機 JWT_SECRET）  
4. 註冊並啟動 `approval-system.service`  

### 5.3 常用指令

```bash
sudo systemctl status approval-system
sudo systemctl restart approval-system
sudo systemctl stop approval-system
sudo journalctl -u approval-system -f
```

### 5.4 環境變數位置

```
/etc/default/approval-system
```

修改後：

```bash
sudo systemctl restart approval-system
```

## 6. 從 Windows / Synology 遷移資料

### 6.1 要複製的目錄

**整個 `data` 目錄**（核心）：

| 項目 | 說明 |
|------|------|
| `approval.db` | 帳號、流程、簽核紀錄 |
| `uploads/` | 上傳附件 |
| `backups/` | 備份 PDF／ZIP |
| `mail-config.json` | Email 設定（若有） |

### 6.2 從 Synology NAS

```bash
# 先在 NAS 停止容器，避免寫入中
# ssh 進 NAS: sudo docker stop approval-system

# 在 Ubuntu 上拉取
rsync -avz --progress \
  tsuming@192.168.99.220:/volume1/docker/approval-system/data/ \
  /opt/approval-system/data/

# 或 SFTP 路徑可能是：
# tsuming@NAS:/docker/approval-system/data/
```

### 6.3 從 Windows

1. 停止 Windows 上的簽核服務  
2. 打包 `data` 資料夾（或使用專案內 `scripts/export-data-bundle.ps1`）  
3. 上傳到 Ubuntu 並解壓到 `/opt/approval-system/data/`  

### 6.4 權限（Docker）

```bash
# 容器內 node 使用者 uid 通常為 1000
sudo chown -R 1000:1000 /opt/approval-system/data
```

### 6.5 重啟

```bash
# Docker
cd /opt/approval-system && docker compose restart

# 原生
sudo systemctl restart approval-system
```

用**原本的帳號密碼**登入（全新庫不是固定弱密碼；見 `data/.admin-bootstrap.txt`）。

## 9. 防火牆與反向代理

### 9.1 UFW

```bash
sudo ufw allow 3847/tcp
sudo ufw reload
sudo ufw status
```

僅內網使用時，可限制來源網段。

### 9.2 Nginx + HTTPS（建議對外時使用）

```nginx
server {
    listen 443 ssl http2;
    server_name sign.example.com;
    # ssl_certificate     /path/fullchain.pem;
    # ssl_certificate_key /path/privkey.pem;

    client_max_body_size 20M;

    location / {
        proxy_pass http://127.0.0.1:3847;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

## 10. 備份與還原

### 備份

```bash
cd /opt/approval-system
./backup-data.sh
# 產生 approval-data-backup-日期.tar.gz
```

建議先停止寫入（`docker compose stop` 或 `systemctl stop`）再備份更保險。

### 還原

```bash
cd /opt/approval-system
docker compose down   # 或 systemctl stop
tar -xzf approval-data-backup-XXXX.tar.gz
# 確認 data/ 已還原
docker compose up -d  # 或 systemctl start
```

## 11. 更新程式

1. 備份 `data/`  
2. 覆蓋新的 `server/`、`public/`、`package.json`、`Dockerfile` 等（**不要清空 data**）  
3. 重建：  

```bash
# Docker
docker compose up -d --build

# 原生
npm install --omit=dev
sudo systemctl restart approval-system
```

cd /opt/approval-system

## 13. 常見問題

| 問題 | 處理 |
|------|------|
| 瀏覽連不上 | `./status.sh`；檢查防火牆；確認容器／服務在跑 |
| `permission denied` 執行 install.sh | `chmod +x install.sh` |
| Docker 權限 denied | 使用者加入 `docker` 群組後**重新登入** |
| 登入失敗 | 是否覆蓋了錯誤的 `approval.db`；全新庫看 `data/.admin-bootstrap.txt` |
| 附件不見 | 確認 `data/uploads` 有一併遷移 |
| PDF 中文亂碼 | 確認 `fonts/kaiu.ttf` 存在；Docker 需 rebuild |
| 埠被占用 | `./install.sh --port 3848` 或改 compose / 環境變數 |
| 磁碟滿 | 清理 `data/backups`、舊 tar.gz |

## 14. 安全性建議

1. **立刻修改**預設管理員密碼  
2. 設定夠長的 **`JWT_SECRET`**（`.env` 或 `/etc/default/approval-system`）  
3. 正式對外請使用 **HTTPS**（Nginx／Caddy）  
4. 不要把安裝包內含密碼的檔案公開上傳  
5. 定期執行 `./backup-data.sh` 並複製到其他主機  
6. 系統與 Docker 定期 `apt update` / 映像更新
