## 二、安裝前準備

1. 確認目標主機可連內網、可連外網（LINE API、必要時 Docker 拉映像）  
2. 準備 **Admin** 帳密（全新庫見 `data/.admin-bootstrap.txt`，上線後立即修改）  
3. 準備公司 Logo（選用）、SMTP（選用）、LINE Developers Channel（選用）  
4. 從 `D:\一鍵安裝包` 取得對應平台資料夾或 zip  

**安全：** 一鍵包**不含** Email 密碼、LINE Token、正式資料庫。密鑰只在安裝後於執行期設定。

## 三、Windows 本機／便攜版

### 3.1 路徑

```text
D:\一鍵安裝包\Windows\ApprovalSystem-Portable\
```

### 3.2 步驟

1. 複製整個 `ApprovalSystem-Portable` 到目標電腦（勿刪 `runtime\node` 若已內建）  
2. 雙擊 **`一鍵安裝.bat`** 或 **`start.bat`**  
3. 瀏覽器開啟 **http://127.0.0.1:3847/**  
4. 以 Admin 登入 → 立即改密碼  
5. （選用）系統設定：公司品牌、Email、備份加密、LINE  

### 3.3 開發機啟動（原始碼）

```powershell
cd C:\Users\TsuMing\Documents\approval-system
# 確認 public\js\ui-helpers.js 存在（否則總覽會報 not defined）
node start-server.js
# → http://127.0.0.1:3847/
```

若缺模組（`pdf-sign.js`、`system-settings.js` 等），從 NAS  
`/volume1/docker/approval-system/server/` 或完整一鍵包還原。

### 3.4 更新

使用包內 **`update.bat`** 或 **`套用此包更新到既有安裝.bat`**，**勿覆蓋**執行期 `data/`。

## 四、Ubuntu（Docker 建議）

### 4.1 路徑

```text
D:\一鍵安裝包\Ubuntu\ApprovalSystem-Ubuntu-Install\
```

### 4.2 步驟

1. 上傳資料夾或 zip 至伺服器，例如 `/opt/approval-system`  
2. 進入目錄，腳本改可執行：

```bash
chmod +x install.sh update.sh status.sh uninstall.sh backup-data.sh
./install.sh --docker
# 或：sudo ./install.sh --native
```

3. 開啟防火牆（若需要）：

```bash
sudo ufw allow 3847/tcp
sudo ufw allow 3848/tcp
```

4. 瀏覽器：`http://<Ubuntu_IP>:3847` 或 HTTPS `:3848`  
5. Admin 登入 → 改密碼 → 系統設定  

### 4.3 更新（保留 data）

```bash
./update.sh
# 或 docker compose up -d --build（勿刪 data volume）
```

詳見包內 `安裝說明.md`、`docs/UBUNTU.md`。

## 五、Synology NAS（正式建議）

### 5.1 路徑與埠

| 項目 | 值 |
|------|-----|
| 主機 | 例：`192.168.99.220` |
| 部署目錄 | `/volume1/docker/approval-system` |
| 容器名 | `approval-system` |
| 網址 | https://192.168.99.220:3848 |

### 5.2 首次安裝（摘要）

1. 上傳 `ApprovalSystem-NAS-Install` 內容至 `/volume1/docker/approval-system`  
2. Container Manager 或 SSH：

```bash
cd /volume1/docker/approval-system
sudo docker compose up -d --build
```

3. 檢查：`http://NAS_IP:3847` 或 `https://NAS_IP:3848`  
4. Admin 登入並修改密碼  

詳見 `docs/SYNOLOGY.md`、包內 `安裝說明.md`。

### 5.3 從 Windows 一鍵更新到 NAS（保留資料）

1. 確認本機已有：`C:\Users\TsuMing\Documents\approval-system`  
2. 一鍵包：`D:\一鍵安裝包\NAS\`  
3. 執行：

```text
D:\一鍵安裝包\NAS\一鍵更新-從這台電腦部署到NAS.bat
```

或：

```powershell
cd C:\Users\TsuMing\Documents\approval-system
$env:NAS_PASS = "<SSH密碼>"
$env:NAS_SKIP_DB = "1"
node scripts/deploy-code-nas.js
# 或 deploy-nas-package.js + NAS_PKG=...
```

4. **必守：** `NAS_SKIP_DB=1`，**不覆寫** `data/approval.db`、備份、上傳、mail-config、憑證  

### 5.4 變更流程（團隊約定）

1. 改本機源碼  
2. **先部署並驗證 NAS**  
3. 使用者確認 OK  
4. **再**同步 `D:\一鍵安裝包` 三平台  
5. 推送 GitHub

## 七、LINE 通知（獨立專案）

### 7.1 路徑

```text
D:\Line 專案
正式服務範例：http://192.168.99.220:3850
```

### 7.2 步驟摘要

1. LINE Developers 建立 Messaging API Channel  
2. 取得 Channel access token、Channel secret  
3. 專案 `.env`：`LINE_CHANNEL_*`、`INTERNAL_API_KEY`、`PORT=3850`  
4. NAS：`/volume1/docker/line-notify`，`docker compose up -d --build`  
5. 簽核「LINE 通知設定」：  
   - 服務網址：`http://192.168.99.220:3850`  
   - API 金鑰 = line-notify 的 `INTERNAL_API_KEY`  
6. 成員對官方帳號傳：`綁定 簽核帳號`  
7. Webhook 需 **公網 HTTPS**（ngrok 或反向代理）  

完整圖文：`D:\Line 專案\docs\LINE通知-完整設定說明.md`  
Ubuntu 包：`D:\Line 專案\dist\LineNotify-Ubuntu-Install\`

## 十、常見問題

| 現象 | 處理 |
|------|------|
| 容器一直重啟 | 查 `docker logs`；常見為 `auth.js`／`labor.js` 不完整 |
| 登入 500 | `labor.parseLeaveUsedManual is not a function` → 還原完整 `labor.js` |
| 總覽 statCardHtml is not defined | 補上 `public/js/ui-helpers.js` 並 Ctrl+F5 |
| 本機連不上 | 確認 `node start-server.js` 在跑、網址為 **3847**（不是舊的 8080） |
| 更新後資料不見 | 錯誤覆蓋了 `data/` → 應永遠 `NAS_SKIP_DB=1` |
