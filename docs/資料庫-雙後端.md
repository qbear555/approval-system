# 資料庫（MariaDB／MySQL）

應用 SQL 仍可寫 SQLite 風格（`datetime('now','localtime')`、`INSERT OR IGNORE`），由 `server/db-adapter` 翻譯成 MySQL。SQLite 引擎與適配檔已移除。

```
MYSQL_HOST=127.0.0.1
MYSQL_PORT=3306
MYSQL_USER=approval
MYSQL_PASSWORD=...
MYSQL_DATABASE=approval
```

正式 NAS：容器內 `MYSQL_HOST=127.0.0.1`（DSM MariaDB 10）。  
本機：`.env` 連 `192.168.99.220:3306` 同一顆 `approval` 庫。
