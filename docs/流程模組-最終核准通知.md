# 簽核流程模組：表單 + PDF 排版 + 最終核准通知

> 版本對應：系統 v1.1.x（約 2026-07-31）  
> 模組格式：`approval-system-workflow` version **2**  
> `module: workflow+form+pdfLayout+finalNotify`

## 1. 模組內容（匯出／匯入一體）

| 欄位 | 說明 |
|------|------|
| `formFields` | 申請單自訂欄位 |
| `steps` | 簽核步驟（含會簽／擇一／表單人員等） |
| `pdfLayout` | PDF 版面類型（`leave`／`credit_limit`／`purchase`／…／`auto`） |
| `finalNotify` | 最終核准後的**系統內**通知設定 |

**不含**：系統設定、SMTP／LINE 密鑰、使用者帳號本體、歷史申請單據。

### 操作位置

- 登入 → **簽核流程** →「匯出全部流程模組」／單一流程「匯出」／「匯入流程模組」
- CLI：`node server/export-workflows.js`、`node server/import-workflows.js <json>`

### API

- `GET /api/workflows/export`
- `GET /api/workflows/:id/export`
- `POST /api/workflows/import`
- `GET /api/workflows/pdf-layout-types`

---

## 2. PDF 排版（`pdfLayout`）

- DB：`workflows.pdf_layout_json`
- 程式：`server/workflow-module.js` + `server/pdf.js`（優先讀流程模組類型）
- 編輯流程時可選版面；`auto` 則依流程名稱推斷

---

## 3. 最終核准通知（系統內，非 Email 抄送）

最終一步（如總經理）核定通過、單據變「已核准」後：

1. 對**選定收件人**寫入系統待確認（表 `final_notify_receipts`）
2. 收件人在**總覽橫幅／待簽核列表／單據詳情**看到待辦
3. 點 **「確認收到」**（請假可顯示「已設定自動回覆／確認收到」）後結案該待辦
4. 申請人本人仍依既有 Email／通知偏好另行通知（與此模組分開）

### 設定項目（編輯流程）

| 項目 | 說明 |
|------|------|
| 啟用／關閉 | 是否使用此模組 |
| 通知說明（label） | 顯示在待確認畫面 |
| 哪些**申請人**需要此模組 | **全部申請人**，或**僅勾選的申請人** |
| 最終**被通知人員** | 核准後要在系統內確認的收件人 |

### 請假申請特別文案

- 預設說明：**「設定 Email 自動回覆」**
- 被通知人員標籤：提醒請假核定後設定／確認 **Email 自動回覆**
- 系統**不會**代為開啟 SMTP 自動回覆，僅系統內待確認提醒

### 信用額度相容

- 若**未**啟用本模組：仍保留舊行為（Email 抄送財務 + 系統內建檔確認）
- 若**已**啟用：以勾選的收件人與申請人範圍為準（建檔確認流程仍獨立）

### 相關 API／資料

- `POST /api/requests/:id/final-notify-ack` — 確認收到
- 表 `final_notify_receipts`（`request_id`, `user_id`, `label`, `created_at`, `acked_at`）
- DB 欄位 `workflows.final_notify_json`

### `finalNotify` JSON 範例

```json
{
  "enabled": true,
  "label": "設定 Email 自動回覆",
  "userIds": [3, 5],
  "users": [{ "id": 3, "username": "hr01", "name": "人資A" }],
  "applicantMode": "selected",
  "applicantUserIds": [10, 12],
  "applicants": [{ "id": 10, "username": "alice", "name": "王小明" }]
}
```

- `applicantMode`: `all`（全部申請人）或 `selected`（僅 `applicantUserIds`）
- 匯入時人員以 `username` 對應本機帳號；不存在則略過

## 4. 部署注意

- NAS 更新請使用 `NAS_SKIP_DB=1`，**勿覆寫**正式 `data/`
- 一鍵安裝包不含正式 DB／Email／LINE 密鑰
- 程式位置：`server/workflow-module.js`、`server/index.js`、`server/db.js`、`public/js/app.js`
