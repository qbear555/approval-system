# PDF 數位簽章 — 製作與設定說明

> 適用：系統 v1.1.x（2026-07 起）  
> 對象：內建 Admin（系統設定）

## 1. 功能說明

下載／備份簽核 PDF 時，可依設定加上**公司 PKCS#12（.p12／.pfx）數位簽章**，以利 Acrobat 等軟體驗證與防竄改。

兩種取得憑證方式：

| 方式 | 說明 |
|------|------|
| **製作數位簽章** | 在系統設定內產生**自簽** .p12（內部使用） |
| **上傳憑證** | 使用 IT／憑證中心核發的正式 .p12／.pfx |

## 2. 製作數位簽章（必填欄位）

路徑：**系統設定 → PDF 數位簽章 → 製作數位簽章（自簽憑證）**

| 欄位 | 必填 | 說明 |
|------|------|------|
| 通用名稱 CN | ✅ | 憑證主體，常填公司名 |
| 組織／公司名稱 O | ✅ | 組織名稱 |
| 國家代碼 C | ✅ | 預設 `TW` |
| 有效年數 | ✅ | 1～30，預設 5 |
| 憑證密碼 | ✅ | 至少 4 字元 |
| 確認憑證密碼 | ✅ | 須與上列一致 |
| 單位 OU | | 選填 |
| 縣市／地區 | | 選填 |
| 聯絡 Email | | 選填，會寫入聯絡資訊 |
| 簽署者顯示名稱 | | 選填，預設＝CN |
| 簽署原因 | | 選填 |
| 製作後自動啟用 | | 建議勾選 |
| 僅已核准加簽 | | 建議勾選 |

點 **「製作並儲存憑證」** 後：

- 檔案寫入 `data/certs/company-sign.p12`
- 密碼存於執行期設定（不下傳完整密文至公開 API）
- 若已有憑證會**覆蓋**

## 3. 驗證

1. 狀態應顯示 **已就緒**
2. 按 **下載測試簽章 PDF**
3. 以 Adobe Acrobat 開啟 → 簽名面板

**注意：** 自簽憑證可能顯示「簽發者不被信任」，內部防竄改仍有效。

請確認專案有：

```text
fonts/Deng.ttf
```

Docker／一鍵包應一併帶上 `fonts/`。
