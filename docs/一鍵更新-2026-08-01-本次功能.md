# 一鍵更新 — 2026-08-01 本次功能包

適用：已安裝的線上簽核系統（**只更新程式，保留 data/**）。

## 本次包含功能

| 功能 | 說明 |
|------|------|
| **總覽公告** | 系統設定維護一則公告；總覽顯示；點查看可讀全文 |
| **公布期間** | 開始／結束時間；超過結束時間自動下架，總覽不顯示 |
| **附件僅檢視** | 查看時可預覽，**不提供下載** |
| **路由還原** | 重新整理瀏覽器後留在目前頁面／單據 |
| **本機控制** | 本機 Server 啟用／停用／控制台與桌面捷徑腳本 |
| **PDF 自簽中文** | 製作數位簽章支援中文 CN／O（修正產生失敗） |

## 一鍵更新怎麼用

### 開發機（本 repo）

雙擊專案根目錄：

```text
一鍵更新.bat
```

選單：

1. **部署到 NAS**（保留 NAS data／Email）  
2. **同步到 D:\一鍵安裝包**（三平台）  
3. **更新本機開發環境並啟動**（埠 8080）  
4. **全部執行（1→2→3）**  

或命令列：

```powershell
cd %USERPROFILE%\Documents\approval-system
node scripts/one-click-update.js --all
node scripts/one-click-update.js --nas
node scripts/one-click-update.js --packages
node scripts/one-click-update.js --local
```

部署 NAS 需環境變數或互動輸入：

```powershell
$env:NAS_PASS = "你的SSH密碼"
$env:NAS_HOST = "192.168.99.220"   # 可選
$env:NAS_USER = "tsuming"          # 可選
node scripts/one-click-update.js --nas
```

### 已安裝的 Windows 便攜版

1. 先用本一鍵更新同步一鍵包，或從 GitHub 拉最新  
2. 進入 `D:\一鍵安裝包\Windows\ApprovalSystem-Portable`  
3. 雙擊 **`update.bat`**（保留 `app\data`）

### NAS 正式站

- 用上面 **部署到 NAS**，或  
- `D:\一鍵安裝包\NAS\一鍵更新-從這台電腦部署到NAS.bat`

## 保留／不覆寫

- `data/approval.db`、uploads、backups  
- `data/mail-config.json`（Email）  
- `data/certs/`、`data/system-settings.json` 中正式設定（公告內容在設定檔，部署**不刪** data）  
- 公告附件目錄 `data/announcements/` 需可寫（權限不足時腳本會嘗試修正）

## 驗證清單

1. 總覽有公告（在公布期間內）  
2. 系統設定可改公布結束時間；到期後總覽消失  
3. 查看公告：附件僅檢視、無下載  
4. 換頁後 F5 仍留在該頁  
5. 本機控制台可啟用／停用 8080
